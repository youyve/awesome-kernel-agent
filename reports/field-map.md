## Interpretation rules

- The denominator is the complete set of **112 Agent entries**; tooling entries are excluded.
- Counts are positive, multi-label annotations. A system contributes once to every value it is explicitly tagged with.
- `Unannotated` means the catalog does not currently contain positive evidence for that facet family; it is not a verified negative.
- A zero-value row means no positive catalog evidence at the research cutoff, not that the research direction is impossible or absent.
- Every controlled value is included. Values are ordered by descending support, then by controlled-vocabulary order and stable key.
- Presentation groups and detailed semantic roles come only from `schema/vocab.yaml`; position is deterministic layout, not rank, sequence, or causality.
- Reverse-index system lists are sorted by system name and then stable ID.

## Coverage provenance audit

- **Workload scope:** the unconditional `operator` migration default was removed. For migrated entries, `operator` is retained where an operator-scoped structured claim supplies positive evidence; otherwise an entry remains unannotated unless another workload-scope value is explicitly present.
- **Artifact level:** coarse levels were deterministically mapped from explicit representation annotations during migration. This is a parent-category derivation, not an independent second evidence channel; no catch-all level was inserted.
- **Representation and hardware:** both fields are structurally present, but the schema permits empty lists. Their full coverage comes from non-empty source annotations for every migrated Agent, not a generated fallback. Coverage therefore means annotated, not independently re-verified and not exhaustive.
